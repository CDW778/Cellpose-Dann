方案:接入 lillianlam DANN 有丝分裂分类器(MIDOG++)到我们的 Cellpose 管线
================================================================

## 0. 目标
现状:Cellpose(一阶段)+ ConvNeXt-V2-tiny(二阶段分类)端到端有丝分裂检测,
test slide04 e2e 5µm F1 ≈ 0.687 ± 0.03。
本方案:把二阶段分类器换成一个公开的、有权重的、mitosis/非 分类器
(lillianlam/multi-stage-dann-model-mitotic-figures,ResNet50 + DANN,训练于 MIDOG++),
零样本接到我们的 Cellpose 候选上,看能否比现在强。二阶段不需要重训(直接加载权重即可跑)。

## 2. 模型规格(已从源码核对)
- DANNModel:ResNet50(ImageNet 预训练)-> 多尺度特征(layer2 512 + layer3 1024 + layer4 2048 = 3584-d)
  -> MLP 二分类(2 类)。
- 训练时用 DANN 域对抗(4 个头:Tumor/Species/Origin/Scanner),目标是跨扫描仪/实验室/物种泛化。
- 标签: 0 = non-mitotic, 1 = mitotic。
- 推理: logits = model.predict_only(x); p_mitosis = torch.softmax(logits, dim=1)[:, 1]。
- 构造(必须用这个 dict 才能 load state_dict):
      num_domain_classes = {'Tumor': 7, 'Species': 2, 'Origin': 4, 'Scanner': 4}
      model = DANNModel(num_classes=2, num_domain_classes=num_domain_classes, lambda_val=0.0)
      model.load_state_dict(torch.load("best_dann_model.pth", map_location="cpu"))
      model.eval()
- 输入: 224x224 RGB 原始窗口(不是白板!),ImageNet 归一化:
      mean=[0.485,0.456,0.406], std=[0.229,0.224,0.225]

----------------------------------------------------------------

## 3. 输入裁剪口径(严格照 224_patch_around_bbox.py)
bbox = [x1, y1, x2, y2]            # 这里用 Cellpose mask 的 bbox
cx = (x1 + x2)//2 ; cy = (y1 + y2)//2
half = 224//2
left = max(0, cx-half) ; top = max(0, cy-half)
right = left+224 ; bottom = top+224
if right > W: right = W ; left = right-224    # 贴左边
if bottom > H: bottom = H ; top = bottom-224  # 贴上边
patch = img.crop((left, top, right, bottom))  # RGB 原图
if patch.size != (224,224): patch = patch.resize((224,224))
注: 固定像素窗口(不按细胞大小缩放)。A 扫描仪 0.2456µm/px 与 MIDOG 量级接近,尺度大致可比。

----------------------------------------------------------------

## 4. 接入方案(零样本,不重训)
对每张 test HPF:
  1) Cellpose(现场, 输入用 RGB) -> 全部 mask
  2) 每个 mask:
       取 mask bbox 中心 -> 按上面口径裁 224x224 原始 RGB 窗口
       -> RGB -> ToTensor -> ImageNet 归一化
       -> DANNModel.predict_only -> softmax[:,1] = p_mitosis
  3) detections = (mask 质心 x,y, p)
  4) 阈值扫描 0.05~0.95 -> 5µm 一对一贪心匹配 -> F1/P/R/TP/FP/FN
对比: 当前最优 e2e 5µm F1(test 04) ≈ 0.687

## 9. 风险与备选
- 域偏移(MIDOG++ -> ICPR2012): 零样本效果未知,必须先实测。
  - 若差 -> 用法2: 加载其权重,在我们 train(00-02)上微调(头/LoRA/全量)。
  - 或用法3: 冻结 backbone,只用 3584-d 特征 + 新头,在我们数据上训。
- 输入必须原始背景(白板会 OOD)。
- mask 中心用 mask bbox 中心(贴合其口径)。
- 只在我们 train 上训练/微调,test(04)仅评估(无泄漏;该权重训练集为 MIDOG++,不含 ICPR2012)。
